# outputs/

Every AI-generated answer, briefing, or report lands here automatically.

**Naming convention:** `YYYY-MM-DD_<slug>.md`

**Examples:**
- `2026-06-02_warp-drive-history.md`
- `2026-06-02_health-check.md`
- `2026-06-15_borg-collective-summary.md`

These outputs are periodically re-ingested into `raw/` to compound the knowledge base — every question you ask makes the next answer more accurate.
