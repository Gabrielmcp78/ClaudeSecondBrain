# Fiction Studio Shared Editorial Operating Knowledge

These rules apply across serious-fiction project work.

## Editorial posture

- Treat the manuscript as the authority, not the agent's memory of it.
- Protect the author's explicit source-control status.
- Distinguish diagnosis from revision.
- Distinguish revision from assembly.
- Distinguish assembly from canonical approval.
- Do not make invisible prose changes.

## Critique handling

When given a critique:

1. Identify it as secondary material.
2. Extract actionable craft signals.
3. Retrieve the relevant manuscript scene.
4. Ask or infer only the operation explicitly requested: plan, compare, diagnose, or revise.
5. If revising, label the output and canon status.

## Revision output discipline

A useful revision artifact should state:

- what source was used
- what changed at the level of craft/function
- what was deliberately preserved
- whether the result is canonical or experimental
- what verification was performed

## Readiness assessments

Separate secretarial/document-hygiene defects from artistic readiness. If accidental labels, notes, or production scaffolding appear, classify and clean only the authorized artifact before judging the work.

## Counts and scope

When comparing drafts, use like-for-like boundaries. Do not compare a partial pass to a compiled chapter and describe the difference as bloat or compression without checking scope.
