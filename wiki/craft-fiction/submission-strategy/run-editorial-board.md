## Focused Variants

### Opening-Pages Conversion

> Run the editorial-board system on these opening pages only. Judge whether each editor-model would request the manuscript, identify the exact loss-of-confidence point for each, and distinguish page-level admiration from full-request probability.

### Full-Manuscript Acquisition

> Run the editorial-board system on the complete canonical manuscript. Judge acquisition viability rather than opening-page promise. Track structural delivery, middle retention, ending fulfillment, category clarity, editorial labor, and the internal case a champion could make to sales and the publisher.

### Query and Agent Route

> Run the editorial-board system on the query package and manuscript opening. Determine whether the pitch accurately represents the book, which agent archetypes can frame it most effectively, and which named routes are supported by current public evidence. Flag every route that remains speculative.

### Revision Comparison

> Run the editorial-board system comparatively on Version A and Version B. Evaluate only differences supported by the supplied text. For each editor-model, state which version increases acquisition confidence, why, and whether the improvement is large enough to alter the submission decision.
