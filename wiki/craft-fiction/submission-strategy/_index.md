## Required Operating Sequence

1. Open `run-editorial-board.md` and use the full launcher or fast command.
2. Verify current editor and agent roles.
3. Read the canonical manuscript pages under review.
4. Identify submission stage and category proposition.
5. Run each editor-model independently.
6. Convene the board debate.
7. Build agent routing only from current, sourced evidence.
8. Issue a final submit, revise, or reposition recommendation with a decision-controlling reason.
