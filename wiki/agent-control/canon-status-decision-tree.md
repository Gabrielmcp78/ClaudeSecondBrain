# Canon Status Decision Tree

Use this before quoting, revising, assembling, or judging any Fiction Studio project material.

## First question: what kind of object is this?

Classify the artifact before using it:

- Manuscript prose: chapter, scene, draft, `.docx`, `.txt`, Google Doc, EPUB export.
- Working artifact: whiteboard, continuity board, transfer board, beat outline, scene map, assembly plan.
- Editorial artifact: critique, board report, margin comments, summary, diagnosis.
- Control artifact: file-control sheet, status ledger, change log, decision registry, task ledger.
- Visual artifact: Canva, design board, image, map, mood reference.
- Unknown: anything without clear status.

## Decision tree

1. If it is the canonical manuscript source, it can be used as prose source after direct verification.
2. If it is experimental/options material, label it experimental and do not treat it as canon.
3. If it is `Approved - Not Assembled`, treat it as approved working material but not canonical manuscript.
4. If it is a visual companion, use it only for visual/reference context unless the user explicitly says otherwise.
5. If it is critique or summary, use it only as secondary interpretation, not as source prose.
6. If it is a file-control artifact, update only after verifying the live/native control surface and explicit authorization.
7. If status is unknown, stop and verify before action.

## Promotion rules

An artifact can move toward canon only with explicit user authorization. The agent must record:

- source artifact
- target canonical location
- exact requested operation
- approval language from the user
- whether the action is planning, revision, assembly, or file-control update

Do not infer promotion from words like `good`, `proceed`, `useful`, `great`, or `green light` unless the target action is explicitly stated.

## Red flags

- A newer timestamp does not automatically mean canonical.
- A cleaned reading draft does not automatically replace source manuscript.
- A critique does not authorize rewrite.
- A board/readiness report is not a manuscript revision.
- A file visible in Drive is not necessarily the right source.
- A connector write capability is not the same thing as edit permission.
