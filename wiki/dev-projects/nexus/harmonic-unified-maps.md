(Source: `harmonic_unified_full_fixed.html`, `harmonic_unified_full_informative.html`, `harmonic_unified_full.html`, `interactive_unified.html`)

This collection of HTML files represents a series of interactive, web-based visualizations of harmonic and musical theory concepts. They appear to be tools for exploring the relationships between notes, chords, and harmonic series in a visual and interactive way.

These tools are likely prototypes or components of the **Nexus** project, given their focus on visualizing complex relationships and their "unified" nature.

## Key Features Observed

*   **Multi-Rail Display**: The visualizations often use a multi-rail or multi-layered display to show different harmonic series or musical modes simultaneously.
*   **Interactive Controls**: The HTML files include JavaScript for user interaction, allowing the user to:
    *   Select different harmonic modes or scales.
    *   Highlight specific notes or chords.
    *   See intervals and chord projections.
    *   Export the current view or data.
*   **Dual-Wave and Coherence**: Some versions include visualizations of wave forms and coherence patterns, suggesting a link to the physics and consciousness theories in the knowledge base.
*   **Dynamic Rendering**: The visualizations are rendered dynamically using JavaScript and SVG, allowing for resizing and real-time updates based on user input.
