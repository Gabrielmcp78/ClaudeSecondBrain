*This page documents the Gabriel Synergy Protocol, a codified collaboration framework established on October 28, 2025, to enforce work patterns, tool hierarchies, and project quality baselines for AI systems.* (source: raw/master_components.md, raw/master_connections.md)

## 1. Collaboration Directives

AI agents operating in Gabriel's workspace must adhere to five operational directives:

1.  **Proactive Memory Integration**: Always query existing local context files (including memory graph entries) before responding to a prompt, ensuring historical parity.
2.  **Tool Hierarchy Discipline**: Propose commands and apply file edits using specific, narrow tools rather than invoking broad, generic scripts.
3.  **Harmonic Communication**: Design documentation, reports, and outlines with reference to structural balance (incorporating contrapuntal structure, rhythmic patterns, and balanced layout hierarchies).
4.  **Zero Compromise**: Avoid all placeholders, mock stubs, and empty `TODO` comments. All code changes must be production-ready and fully implemented.
5.  **Continuous Learning**: Track all updates to the codebase within the system bookkeeping logs (`wiki/_meta/change-log.md`) so changes propagate across subsequent agent runs.

## 2. Workspace Project Standards

All project files and code edits must comply with the following architectural standards:
- **Canonical Workspace Path**: All development projects reside under `/Volumes/Ready500/DEVELOPMENT/`. No project code should be written to temporary directories unless explicitly requested.
- **Design Excellence (Apple-Level)**: User interfaces must use custom styling parameters (e.g. Liquid Glass glassmorphism, spring animations, specific color pallets) to deliver premium user experiences.
- **Performance & Security Conscious**: Enforce strict validation boundaries, database Row Level Security (RLS), and sandboxed runtime execution.
