# raw/

Drop anything here — articles, episode notes, transcripts, PDFs, images, web clips, pasted text.

**Rules:**
- Never organize files here manually; that is Claude's job.
- Claude marks processed files by appending `_done` to the filename.
- Supported: `.md`, `.txt`, `.pdf`, images (`.png`, `.jpg`).

To trigger ingestion, open a Claude Code session at the repo root and run:

> "Read everything in raw/ and compile the wiki following the rules in CLAUDE.md."
